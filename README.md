# Papa's Döner — The Legend Returns 2026

A single-page marketing website for **Papa's Döner**, a premium döner restaurant
in Stuttgart, Germany. The brand concept is **"Dark Luxury"** — presenting street
food as a high-end, fine-dining culinary experience. Content is in German.

## Contents

| File | Description |
|------|-------------|
| `code.html` | The complete website — a self-contained HTML page (Tailwind via CDN + vanilla JS). |
| `DESIGN.md` | The design system spec: color palette, typography, layout, components. |
| `screen.png` | Full-page screenshot preview. |

## Viewing

Open `code.html` in any modern browser. An internet connection is required —
fonts (Google Fonts), Tailwind (CDN), and images are loaded from external URLs.

## Tech

- **Styling:** Tailwind CSS (CDN build) with a custom theme (the "Artisanal Obsidian" palette).
- **Fonts:** Playfair Display (headlines), Hanken Grotesk (body), JetBrains Mono (labels), La Belle Aurore (captions).
- **JS:** Vanilla — scroll-reveal animations, nav blur on scroll, hero parallax, button micro-interactions.
